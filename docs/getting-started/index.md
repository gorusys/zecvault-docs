# Getting Started

ZecVault is available as a native desktop app on Linux, macOS, and Windows — and as a web app you can run locally or deploy to the cloud. This guide walks you from download to your first saved goal.

---

## What you'll need

- **5 minutes** to set up your wallet
- **Pen and paper** (or a secure offline location) to write down your 24-word seed phrase
- One of the following:
    - A desktop computer running Linux, macOS, or Windows
    - A modern web browser (Chrome, Firefox, Safari, Edge)

!!! warning "Write down your seed phrase"
    ZecVault is non-custodial. If you lose your 24-word seed phrase and your device breaks, your funds are **permanently unrecoverable**. There is no "forgot password" — back up early, back up offline.
